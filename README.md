# ♟️ Tactical Loot Chess

Пошаговая тактическая игра 8×8 для двух игроков в браузере. Это шахматы с лутом и оружием: собирайте ящики, находите легендарное снаряжение и уничтожьте вражеского **Командира**.

Играть можно по интернету (у каждой пары своя комната по ссылке), в локальной сети или вдвоём за одним компьютером.

- Пиксель-арт, нарисованный кодом: без картинок и внешних файлов, резкий на Retina-экранах
- Процедурный звук на Web Audio API
- Сервер проверяет каждый ход и скрывает от соперника вражеские мины и содержимое ящиков
- Чистый HTML5 + Canvas + Vanilla JS, без сборщиков. Запуск одной командой

## 🚀 Быстрый старт

```bash
git clone https://github.com/OWNER/tactical-loot-chess.git
cd tactical-loot-chess
npm install
node server.js
```

Откройте `http://localhost:3000`. Сервер выведет в консоль адреса для подключения из локальной сети (например, `http://192.168.1.5:3000`). Нужен [Node.js](https://nodejs.org) 18 или новее.

Другой порт: `PORT=3001 node server.js`.

## 🌍 Играть с друзьями через интернет

### Вариант 1: свой бесплатный сервер на Render (для всех и всегда)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/OWNER/tactical-loot-chess)

1. Нажмите кнопку выше и войдите в Render (можно через GitHub).
2. Нажмите **Apply**. Через пару минут игра будет доступна по адресу вида `https://tactical-loot-chess-xxxx.onrender.com`.
3. Отправьте эту ссылку друзьям.

Бесплатный сервер засыпает после 15 минут без игроков, и первое открытие после сна занимает около минуты. Подойдёт и любой другой хостинг с поддержкой Node.js или Docker: в репозитории есть `Dockerfile`.

### Вариант 2: временная публичная ссылка со своего компьютера

Запустите игру (`node server.js`) и в соседнем окне терминала выполните (нужен [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/), на Mac: `brew install cloudflared`):

```bash
cloudflared tunnel --url http://localhost:3000
```

Появится публичная `https://…` ссылка, отправьте её другу. Она работает, пока открыт терминал.

## 🚪 Комнаты

- Без кода в ссылке вы попадаете в общую комнату **MAIN**.
- **«Новая комната»** создаёт приватную комнату со ссылкой вида `/?room=K7QX2`. Отправьте её другу, и он попадёт прямо к вам.
- **«Войти по коду»** открывает комнату по коду.
- **«Тест на одном экране (1 ПК)»**: играть за обе стороны по очереди.
- **«Сбросить комнату»** помогает, если сессия зависла.
- Обновили страницу (F5) посреди матча? Вы вернётесь в свою партию.

## 📜 Правила

**Цель:** уничтожить вражеского Командира.

**Ход:** за ход можно задействовать **2 разных юнита**, у каждого есть **1 Движение** и **1 Действие**. Окошко под доской показывает, сколько ходов осталось. На ход даётся 60 секунд, потом ход передаётся автоматически.

| Юнит | HP | Ход | Урон | Дальность | Особенность |
|---|---|---|---|---|---|
| Командир ×1 | 10 | 2 | 2 | 2 | Его гибель означает поражение |
| Штурмовик ×2 | 6 | 3 | 2 | 2 | |
| Снайпер ×2 | 4 | 2 | 3 | 2–4 | Не стреляет вплотную, не может двигаться и стрелять в один ход |
| Разведчик ×1 | 5 | 4 | 1 | 1 | Быстро собирает лут |

Стены блокируют движение и линию огня.

### 📦 Лут

Ящики падают каждые 2 раунда. Чем дольше матч, тем выше **уровень лута**: ящики падают чаще и по несколько сразу. Наступите на ящик, чтобы открыть его.

| Предмет | Эффект |
|---|---|
| 🔫 Дробовик | Выстрел в упор: урон цели, урон соседним клеткам и отталкивание |
| 🛡 Энергощит | Поглощает следующие попадания |
| 🚀 Джетпак | Прыжок через стены и юнитов |
| ✚ Нано-аптечка | Мгновенное лечение и снятие контузии |
| 💣 Мина | Скрытая ловушка: урон, остановка и контузия врага |
| 🍀 Клевер удачи | Удача команды на несколько ходов. Выпадает чаще всего, но не повторяется, пока действует |

**Редкость:** Обычный · Редкий · Эпический · Легендарный · Мифический. Чем выше редкость, тем больше урона, зарядов и дальность. **Удача** повышает шанс редкого лута и **двойного дропа**, когда рядом выпадает второй ящик.

## ⌨️ Управление

| | |
|---|---|
| ЛКМ | выбрать юнита, переместиться, атаковать |
| ПКМ / Esc | отмена |
| Enter / Пробел | завершить ход |
| Tab | следующий юнит |
| M | звук вкл/выкл |

## 🗂 Структура

```
server.js          авторитетный сервер: комнаты, правила, урон, лут, таймер, туман войны
public/shared.js   общие правила (линия огня по Брезенхэму, BFS, редкость) — сервер + клиент
public/game.js     клиент: Canvas-рендер, анимации, интерфейс
public/sprites.js  пиксельные спрайты 16×16 в виде матриц символов
public/sound.js    синтезатор звуков на Web Audio API
public/index.html, public/style.css
```
